Exercício — Que tipo de método usar?

Instruções:
Para cada situação abaixo, responda:

1. O método deve ser:
   - ( ) Instância (self)
   - ( ) Classe (@classmethod)
   - ( ) Estático (@staticmethod)

2. Explique rapidamente o porquê


Situação 1:
Um método que retorna o saldo atual de uma conta bancária.
- Ele usa o valor armazenado dentro do objeto.

R: O metodo deve ser de Instancia (self), pois esta utilizando apenas o valor armazenado dentro do proprio objeto, não tendo necessidade de um classmethod ou staticmethod


Situação 2:
Um método que altera a taxa de juros para todas as contas do sistema.
- Essa taxa é compartilhada entre todas as contas.

R: deve ser metodo classe, pois a taxa é compartilhada entre todas as contas da classe e não apenas uma só, 


Situação 3:
Um método que verifica se um CPF tem o número correto de dígitos.
- Ele recebe um CPF e retorna True ou False
- Não usa nenhum atributo da classe ou do objeto

R: deve ser estatistico, pois não usa atributo nem de classe nem de objeto e é utilizado para verificar o cpf, assim sendo necessário um estatistico, pois um dos seus usos é para verificações


Situação 4:
Um método que cria uma conta bancária a partir de um dicionário:
dados = {"titular": "João", "saldo": 1000}
R: classe pois está criando um objeto apartir de um dicionario exterior


Situação 5:
Um método que calcula o valor de um desconto:
valor_final = valor - (valor * desconto)
- Não depende de nenhum dado da classe
R: estatistico, pois não depende de nenhum dado da classe e está sendo utilizado apemas para calcular o valor do desconto, cujo é um dos momentos para se usar estatistico


Situação 6:
Um método que altera o nome do titular da conta.
- Ele modifica um dado específico de um objeto
R: um de instancia, pois esta modificando diretamente um dado especifico de um objeto, sem modificar classe alguma


Situação 7:
Um método que retorna quantas contas já foram criadas.
- Existe um contador armazenado na classe

R: Metodo de classe, pois esta sendo utiliado para retornar quantas contas foram criadas, cujo o contador esta armazenado na classe,
